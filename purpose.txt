Назначение системы контроля версий (СКВ)
Система контроля версий (Git) предназначена для хранения истории изменений
проекта и организации совместной работы над файлами.
Основные возможности:
- фиксация состояния файлов на любой момент времени (коммит);
- определение автора и даты каждого изменения;
- сравнение версий между собой и возврат к предыдущей версии;
- параллельная разработка в отдельных ветвях без риска для основной ветви;
- объединение ветвей и разрешение конфликтов слияния;
- хранение полной копии истории на локальном компьютере (распределённая модель).
GitHub - крупнейший веб-сервис для хостинга IT-проектов и их совместной
разработки, основанный на системе контроля версий Git.
